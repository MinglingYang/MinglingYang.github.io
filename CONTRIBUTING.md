# Contributing

Thank you for helping improve this academic website template. Contributions that make setup clearer, improve accessibility, fix bugs, or add reusable features are welcome.

## Before opening an issue

- Search existing issues first.
- For a bug, include the affected page, browser, screen size, expected result, and screenshot when useful.
- For a feature, explain how it helps other students or researchers—not only one private deployment.
- Never include passwords, API keys, unpublished research data, student records, or private contact details.

## Local development

1. Fork the repository and create a focused branch.
2. Install dependencies with **bundle install**.
3. Start the site with **bundle exec jekyll liveserve**.
4. Make the smallest change that solves the problem.
5. Run **bundle exec jekyll build** before submitting.
6. Check both desktop and mobile layouts.

## Pull requests

- Describe what changed and why.
- Include before-and-after screenshots for visual changes.
- Keep personal profile content out of reusable template changes.
- Update the English and Chinese documentation when setup behavior changes.
- Preserve MIT license notices and third-party attribution.

By submitting a contribution, you agree that it may be distributed under the repository's MIT License.
